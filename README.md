# 剑来光阴 · 微信小程序

《剑来》人物、势力、地点、法宝、语录、时间线和关系图谱的交互式阅读小程序。项目使用 Taro 4、React 18 和 TypeScript 构建，关系图谱基于 AntV F6。

## 功能地图

- 首页：热门人物、每日金句和主要内容入口。
- 人物：人物列表、详情、境界、势力、关系和语录。
- 世界：势力、地点、法宝和世界观内容。
- 图谱：人物关系浏览、筛选与人物信息面板。
- 时间线与地图：按事件和空间理解剧情。
- 搜索：统一检索人物、势力、地点和法宝。
- 对比：人物多维度对比及分享卡片。
- 分享：人物、金句、法宝、势力和对比卡片。
- UGC：用户可提交资料或图片修订建议，由服务端审核后进入数据管道。

## 技术结构

```text
src/pages/          页面与路由
src/components/     通用组件、图谱组件和 UGC 入口
src/data/           数据类型、加载与缓存逻辑
src/utils/          分享、埋点、卡片生成和 Canvas 工具
src/styles/         水墨风设计系统
src/assets/         图标与必要的客户端素材
public/             H5/开发态轻量回退资源
```

数据由独立的数据管道仓库生成，通过 HTTPS 静态接口供小程序加载。大批人物/法宝图片由资源服务器托管，不直接放入 Git 或小程序包体。

## 本地开发

```bash
npm install
npm run dev:weapp
```

微信小程序构建：

```bash
npm run build:weapp
```

开发模式可在 `config/dev.ts` 中将 `process.env.API_BASE` 指向本地静态服务。生产凭证、私钥和 `.env` 不得提交。

## 资源与安全边界

- 小程序码和分享模板是公开产品素材，可以进入仓库。
- 生成图片大库、重复 JSON、构建产物和本机缓存不进入仓库。
- UGC 代码进入仓库不等于已获准上线；发布前仍需完成隐私披露、数据最小化和服务端防滥用评审。
- GitHub 上传与微信小程序发布相互独立，本仓库的提交不会自动部署。
