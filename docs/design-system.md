# 水墨风设计系统

## 设计目标

界面以宣纸、墨色、朱砂、靛青和竹青构成统一视觉语言。信息层级主要依靠留白、字号、墨色浓淡和轻边框，不依赖高饱和渐变或厚重阴影。

## 核心色彩

| 角色 | 色值 | 用途 |
|---|---|---|
| 焦墨 | `#1a1a1a` | 页面标题、强强调 |
| 浓墨 | `#333333` | 正文 |
| 重墨 | `#666666` | 次要信息 |
| 宣纸白 | `#f7f6f2` | 页面背景 |
| 朱砂 | `#b03a2e` | 印章、高亮、错误 |
| 靛青 | `#485a6c` | 链接、品牌色 |
| 竹青 | `#5d7a5d` | 成功、部分标签 |
| 赭石 | `#b8860b` | 警告、法宝信息 |

真实变量以 `src/styles/theme.scss` 为单一来源。

## 排版与间距

- 字号采用从 `20px` 到 `64px` 的固定层级，正文默认行高 `1.6`。
- 间距以 `8px` 为基础步长。
- 卡片圆角以 `24px` 为主，轻阴影只用于区分层级。
- 长文本必须限制行数或提供可展开入口，不用缩小字号解决溢出。

## 页面结构

- 首页突出人物与金句，主要入口保持一屏可识别。
- 列表页使用统一筛选栏、卡片密度和空状态。
- 详情页按身份、内容、关系、语录和分享动作分区。
- 图谱页将导航、筛选、画布和人物信息面板分层，避免手势冲突。
- 分享卡片使用 750px 基准画布，统一二维码页脚与品牌署名。

## 分享卡片

人物、金句、法宝、势力和人物对比使用统一 Canvas 工具：

- 宣纸或水墨背景；
- 金色细线与轻量装饰；
- 自动换行与最大行数；
- 加载失败时使用渐变或文字占位；
- 底部保留公开小程序码和识别提示。

新增卡片类型应复用 `src/utils/cardUtils.ts`，避免重复实现图片加载、圆角、阴影、文本换行和导出逻辑。

## 可访问性

- 正文与背景保持足够对比度。
- 点击区域不只依赖图标含义，应配文字或无障碍标签。
- 颜色不能成为状态的唯一表达。
- 动效、缩放和惯性操作必须提供清晰边界与失败回退。
